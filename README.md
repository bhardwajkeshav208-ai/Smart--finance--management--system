# 💰 Smart Finance Management System

A comprehensive Python-based Smart Finance Management System designed for both **Personal Finance** and **Business ERP** management.

## 🚀 Features

### 👤 Personal Finance
- Income Tracking
- Expense Tracking
- Budget Management
- Saving Goal Tracker
- Financial Health Score
- Category-wise Expense Summary
- Search by Date & Category
- Monthly Reports

### 🏢 Business ERP
- Daily Sales Entry
- Expense Management
- Profit & Loss Calculator
- Inventory Tracker
- Customer Management
- Vendor Ledger
- GST Calculator
- Cash Flow Management
- Employee Payroll
- Invoice Generator

## 🛠 Tech Stack

- Python
- CustomTkinter / Tkinter
- SQLite
- JSON
- Object-Oriented Programming (OOP)

## 📂 Project Structure
